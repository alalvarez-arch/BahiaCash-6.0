# BahiaGo V6

PWA de turnos, tareas y equipo para hosteleria de lujo.

## Novedades V6
- Guardar horario en PDF
- Vista previa semanal al generar
- Prioridad de tareas principales (Terraza pequena menos prioritaria)
- Dias libres solo los marcados
- Iconos Apple / Android / web

## Subir a GitHub Pages
1. Sube a la **raiz** del repo todo el contenido de esta carpeta.
2. Settings → Pages → branch `main` → folder `/ (root)`.
3. URL: `https://USUARIO.github.io/REPO/`

Si no sube `.nojekyll`: Create new file → nombre `.nojekyll` (vacio) → Commit.

## Instalar
- Android (Chrome): Instalar aplicacion
- iPhone (Safari): Compartir → Anadir a pantalla de inicio
